# ShopCart — тестування iOS у GitHub Actions

Навчальний проєкт для розрахункового завдання «Інструменти тестування iOS додатків».
Xcode-проєкт створюється автоматично (XcodeGen) на хмарному Mac, локальний Mac не потрібен.

Запуск: вкладка **Actions → iOS tests → Run workflow** (або будь-який push).
Результат: відкрийте завершений запуск → блок **Summary** (таблиці результатів і покриття) та **Artifacts → test-results**.
